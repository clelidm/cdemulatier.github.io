# Group

<span style="font-size: medium"><strong>Current Main Research focus</strong></span>
<p style="padding: 0px 22px 0px">One of the current main focuses of the group is on the development of <strong>new tools</strong> to uncover and model <strong>high order patterns of data</strong>.</p>
<a href="http://lptms.u-psud.fr/clelia-de-mulatier/files/2021/07/Picture_PhD-1.pdf"><img class="alignright" style="float: right" src="http://lptms.u-psud.fr/clelia-de-mulatier/files/2022/07/Picture_MCM.png" width="301" height="153" border="0" /></a>
<p style="padding: 0px 22px 0px"><strong>Highlight:</strong> Check our paper on the use of Minimally Complex spin Models (MCM) to identify and model groups of highly correlated variables in binary data: <a href="https://arxiv.org/abs/2008.00520" target="_blank" rel="no noopener opener">here</a>.</p>
<p style="padding: 0px 22px 0px">The procedure performs exact Bayesian model selection and takes into account all possible high order patterns of data (3-body correlations, 4-body correlations, etc.) in the detection of these "communities" of variables. The use of Minimally Complex Models provides robust predictions on dependencies between variables.</p>

<ul>
<strong>Codes:</strong> You can find our codes that performs this "high-order community detection" for binary data on Github:
&nbsp;&nbsp;&nbsp;&nbsp;-- <a href="https://github.com/clelidm/MinCompSpin" target="_blank" rel="no opener noopener">MinCompSpin</a> performs an exhaustive search and works best for systems with a small number of variables (&lt;= 15).
&nbsp;&nbsp;&nbsp;&nbsp;-- <a href="https://github.com/clelidm/MinCompSpin_Greedy" target="_blank" rel="no opener noopener">MinCompSpin_Greedy</a> performs a greedy search and works best for systems with a large number of variables (up to 128 variables).</ul>
<ul>
<strong>Python Package:</strong> Our Python package to analyze discrete data with minimally complex models:
&nbsp;&nbsp;&nbsp;&nbsp;-- <a href="https://github.com/DM-Lab-UvA/MinCompSpin" target="_blank" rel="no opener noopener"><strong>MinCompSpin</strong></a>, for discrete datasets with variables that can take up to 10 values, for up to 128 variables.
</ul>
